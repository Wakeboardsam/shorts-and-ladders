# Shorts and Ladders

Home Assistant add-on store for the TQQQ ladder bot. It holds no bot code:
each add-on folder points Home Assistant at a prebuilt image.

To add it, go to **Settings → Add-ons → Add-on Store → ⋮ → Repositories** and
paste `https://github.com/Wakeboardsam/shorts-and-ladders`.

New to this? Follow the step-by-step [setup guide](SETUP_GUIDE.md).
